# 📊 Nykaa Sales Analytics Dashboard | Microsoft Excel

## 📌 Project Overview
This project focuses on analyzing Nykaa sales data using Microsoft Excel to identify sales trends, customer preferences, product performance, discount patterns, and product returns.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers & Timeline
- Interactive Dashboard

## 📈 Key Performance Indicators (KPIs)
- Total Net Sales: ₹19.07 Lakhs
- Total Units Sold: 2,324
- Average Customer Rating: 4.1/5
- Top Payment Mode: Wallet
- Top-Selling Brand: Wow Skin Science

## 📊 Dashboard Analysis
- Monthly Net Sales Performance
- Customer Segment Revenue Analysis
- City-wise Net Sales Analysis
- Top 10 Best-Selling Products
- Channel-wise Net Sales Analysis
- Brand-wise Customer Satisfaction
- Brand Discount Performance Analysis
- Product Return Analysis

## 🎯 Project Objectives
- Analyze monthly sales trends.
- Understand customer purchasing behavior.
- Identify top-performing products and brands.
- Evaluate payment preferences and product returns.
- Generate meaningful business insights to support decision-making.

## 💡 Key Learnings
- Data analysis using Excel.
- Interactive dashboard development.
- Data visualization and KPI reporting.
- Extracting business insights from sales data.
